# 211U — Dual SoundCloud Player

**[Открыть плеер →](https://svme-prxblem.github.io/soundcloud-dual-player/)**

Два трека SoundCloud. Одно звучание. Вставь две ссылки и запусти их вместе.

</div>

Статический сайт без сборки и без сервера: работает прямо в браузере через официальный SoundCloud Widget API.

## Как пользоваться

1. Скопируй обычную ссылку на трек, например `https://soundcloud.com/artist/track-name`.
2. Вставь её в поле трека A и нажми **«Загрузить»**. То же самое сделай для трека B.
3. Когда оба плеера будут готовы, нажми **«Запустить оба»**.
4. Общий ползунок перематывает оба трека сразу, громкость у каждого трека своя.
5. **«Ссылка на треки»** копирует адрес страницы с обоими треками. Отправь его другу: у него треки загрузятся сами.

## Возможности

- Принимает обычные HTTPS-ссылки с домена soundcloud.com, embed-код искать не нужно.
- Общие **«Запустить оба»**, **«Пауза»** и **«С начала»**.
- Общий ползунок позиции. Шкала равна длине более длинного трека. Если позиция дальше конца короткого трека, он останавливается на финише, а при перемотке назад снова включается, если идёт воспроизведение.
- Независимая громкость для каждого трека.
- Название и обложка трека подтягиваются из SoundCloud после загрузки.
- Ссылка с треками в адресе (`?a=…&b=…`): при открытии такой ссылки треки загружаются автоматически.
- Интерфейс на английском и русском. Язык берётся из настроек браузера, его можно сменить переключателем **EN / RU** в верхней строке; выбор запоминается.
- Устанавливается как приложение (PWA).

## Ограничения

- Трек должен быть публичным и разрешённым для встраивания.
- Короткие ссылки (`on.soundcloud.com`), приватные треки и региональные ограничения могут не работать.
- Widget API не гарантирует идеально синхронный старт: оба `play()` отправляются одновременно, но звук может стартовать с небольшой разницей.
- Для звука нужен интернет: офлайн кешируется только оболочка сайта.

## Структура

- `index.html` — разметка.
- `style.css` — оформление.
- `app.js` — проверка ссылок, создание плееров и управление Widget API.
- `i18n.js` — переводы интерфейса (английский, русский) и переключатель языка.
- `assets/` — логотипы и иллюстрации (WebP).
- `fonts/` — Montserrat (латиница + кириллица), хранится локально, чтобы работал офлайн-кеш.
- `icons/` — иконка вкладки и иконки приложения.
- `manifest.webmanifest`, `sw.js` — PWA: установка и кеш оболочки.

## Как добавить язык

Добавь в `i18n.js` новый словарь рядом с `en` и `ru` с теми же ключами, затем добавь кнопку с `data-lang="<код>"` в блок `.lang-switch` в `index.html`. Если какого-то ключа нет, используется английский.

## Публикация

Сайт публикуется через GitHub Pages прямо из ветки `main` (папка `/`). Каждый `git push` в `main` обновляет сайт примерно за минуту.

После изменения файлов увеличь версию `CACHE_NAME` в `sw.js` (например, `dual-player-shell-v6` → `v7`), иначе у тех, кто уже открывал сайт, может остаться старая версия из кеша.

Все пути в проекте относительные, поэтому сайт работает и в подпапке (`/soundcloud-dual-player/`), и на собственном домене.

## Локальный запуск

Нужен любой локальный сервер, например:

```
python -m http.server 8000
```

и открыть http://localhost:8000. Открытие `index.html` двойным кликом тоже работает, но без установки приложения и офлайн-кеша.
